# jai-simdutf

Jai bindings for the [simdutf](https://github.com/simdutf/simdutf) library v9.0.0.

Generate bindings using `jai generate.jai`, and compile static libraries with `jai generate.jai - -compile`.

Currently Windows and MacOS (ARM64) are supported.

PRs welcome.
